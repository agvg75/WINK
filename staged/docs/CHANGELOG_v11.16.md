# NIKE application v11.16

## Hub organization

- Places motor-output tools first, ordered as Locomotion, Rhythmic programs, and Sensory-guided behavior.
- Follows those groups with Physiology, Anatomy and morphology, and Acquisition and utilities.
- Makes the category sequence explicit so adding or moving a tool cannot accidentally reorder the Hub.
- Appends any future unrecognized category after the established workflow rather than hiding it.

## Installation

- This is an application-only update. Existing NIKE v11.15 installations can install it through **Help > Check for updates**; no new runtime installation is required.
