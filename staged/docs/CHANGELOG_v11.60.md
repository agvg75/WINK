# NIKE Lab Tools v11.60

Egg-counting workbench migration.

- Straight-distance calibration now opens in the NIKE workbench layout instead
  of a raw matplotlib `ginput` popup.
- Worm-trace calibration now uses the same workbench with visible polyline
  feedback, undo, clear, cancel, and finish controls.
- Egg analysis ROI drawing now uses the shared workbench with visible polygon
  feedback.
- Reference egg marking now uses the shared workbench and allows multiple egg
  examples in one session, with left-click accept/green, right-click
  reject/red, undo, clear, cancel, and finish actions.
- No egg-counting measurement formulas were changed in this pass; this update
  continues the staged move toward the single-window NIKE cockpit.
- Carries forward v11.59 shared workbench helpers and pharyngeal pumping review
  migration.
