# NIKE Lab Tools v11.61

Pharyngeal pumping cockpit migration.

- The pharyngeal pumping main window now follows the NIKE cockpit layout:
  controls on the left, image/ROI navigator in the center, and a hideable
  process/timing hood on the right.
- Controls and hood can be hidden or restored using the buttons or keyboard
  shortcuts (`c` for controls, `h` for hood).
- The right hood now updates during recording load, ROI save/cancel/clear,
  interval analysis, automatic analysis, and failures.
- Existing live semi-transparent ROI drawing, ROI clear/redraw, frame
  navigation, interval marking, and PumpKin-style analysis are preserved.
- No pharyngeal pumping measurement formulas were changed in this pass.
- Carries forward v11.60 egg-counting workbench migration.
