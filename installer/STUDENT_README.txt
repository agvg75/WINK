AGVG LAB TOOLS - STUDENT INSTALLATION

Requirements: Windows 10/11 64-bit and about 4 GB free.

The Complete Offline package needs no internet connection. The smaller Online
package needs internet during setup. In both cases, students do not manually
install Python, scientific libraries, Java, or Fiji.

1. Extract the entire ZIP. Do not run the installer from inside the ZIP.
2. Double-click Install_Lab_Tools.bat.
3. Wait while setup installs its private Python, libraries, Fiji, and Java.
4. Start AGVG Lab Tools from the new Desktop shortcut.

Administrator rights are normally unnecessary. If setup fails, send
install_log.txt to the lab. The uninstaller never removes experimental data.
